# المحاكمة — Android starter project

مشروع Android أولي لتطبيق «المحاكمة»، مبنيّ بـ Kotlin وJetpack Compose وبواجهة عربية من اليمين إلى اليسار، مع هوية بنفسجية داكنة.

## ما الموجود في هذه النسخة؟

- هوية إطلاق تكيفية تمزج القناع وميزان العدالة بألوان بنفسجية داكنة.
- شاشة افتتاح سينمائية متحركة بحلقات ضوئية بطيئة، وخط ضوء بنفسجي، وظهور تدريجي للشعار والعبارة، مع خيار تجاوز المشهد.
- أجواء سينمائية خفيفة عبر الشاشات: ضباب ضوئي متحرك، ذرات بنفسجية بطيئة، تظليل ناعم للحواف، وانتقالات متحركة بين الأقسام.
- شاشة الاسم قبل رسالة الترحيب الأدبية، مع حفظ الاسم محليًا.
- **بنك من ١٬٠٠٠ عقدة سؤال**: ١٦ سؤالًا تأسيسيًا متفرعًا، و٩٨٤ سؤالًا مبنيًا من مصفوفة منظمة تضم ١٢ مجالًا نفسيًا، و١٢ سياقًا حياتيًا، و٧ عدسات تأملية. المسار المتسلسل يتناوب بين المجالات والسياقات لتقليل تكرار الموضوع الواحد، وتختلف تفاصيل الخيارات وفق الموقف. لكل سؤال ثلاثة خيارات ذات وسوم ومسارات تالية؛ الخيارات البديلة تتجه إلى أسئلة لاحقة مرتبطة دلاليًا، مع إبقاء مسار متصل يضمن الوصول إلى جميع العقد.
- تحليل يستند إلى الإجابات الواقعة على **المسار النشط فقط**؛ عند اختيار فرع بديل تُستبعد إجابات الفرع المتروك من الأدلة الحالية بدل تلويث الانعكاس ببيانات قديمة.
- انعكاسات قائمة على الاختيارات الفعلية في كشف القناع، وشجرة الوجوه، وذاتك الأخرى، والمحكمة الداخلية، وصدى الماضي، والغرفة الصامتة، وملف الانعكاس. تُعرض الأنماط بوصفها احتمالات قابلة للمراجعة، لا تشخيصًا نفسيًا ولا حقائق قطعية.
- ساعة استخدام تراكمية تعتمد وقتًا أحادي الاتجاه، وتعدّ وقت الواجهة الأمامية بعد بدء المحاكمة فقط، وتتوقف في الخلفية، وتحفظ الفروقات دوريًا وبين الجلسات.
- مقطع موسيقى محيطية محلي واحد يعمل بحلقة. تم تلطيف وصلة البداية والنهاية داخل الملف الصوتي، ويُكتم أو يُعاد من إعدادات التطبيق مع حفظ الاختيار؛ وتنخفض الموسيقى تدريجيًا تحت صوت الطيف ثم تعود بعد انتهائه.
- «طيف الذات» كشخصية بصرية متحركة: ضباب متعدد الطبقات، وهج يتنفس، أشعة خافتة، وانجراف وحركة وجه إشارية أثناء الكلام، مع حوار يعتمد على أدلة الإجابات. يجري إغلاقه بعد مهلة متناسبة مع طول النص حتى لا تُقطع الانعكاسات الطويلة مبكرًا.
- تفضيل صوت عربي متاح على الجهاز، مع إبطاء الإلقاء وخفض الطبقة وتطبيع الوقفات. جودة مخارج الحروف وطبيعية الأداء تظل معتمدة على محرك Android TTS والصوت المثبت؛ لا يُدّعى أنه صوت بشري استوديوي.
- تعطيل خيارات النسخ والقص وتحديد الكل في قائمة النصوص داخل حقول الكتابة، مع بقاء اللصق متاحًا. هذا لا يمنع تصوير الشاشة بكاميرا خارجية أو وسائل نظام خارج نطاق التطبيق.
- بند المطوّر **Aram Aoyal** ورابط Telegram: https://t.me/ro_gy
- اختبارات وحدة لبنك الأسئلة، والتفرع، وتصفية الأدلة، ودفتر الوقت، وسياسة مستوى الموسيقى؛ واختبار Android آلي لتخزين الاسم والإجابات والكتابة الحرة والكتم ووقت المحاكمة، مضبوط للتشغيل عبر محاكي في GitHub Actions.

## نطاق المحتوى ومنهجه

عدد العقد في بنك البيانات هو **١٬٠٠٠ بالضبط**، لكن ذلك لا يعني أن المستخدم سيجيب عنها كلها في جلسة واحدة؛ التفرعات تقوده إلى مسار يختلف وفق اختياراته، وتظل العقد البديلة موجودة وقابلة للوصول عبر إجابات أخرى. الأسئلة الـ٩٨٤ الموسّعة تنتج من تركيب منظم لمجالات وسياقات وعدسات تأملية، وليست ٩٨٤ نصًا منفصلًا كُتب كل واحد منها يدويًا من الصفر. لهذا ينبغي إجراء مراجعة تحريرية بشرية شاملة لتنوع الصياغة وملاءمة الخيارات قبل النشر العام.

التحليلات انعكاسات سلوكية تأملية وليست أداة تشخيص. كما أن ضبط سرعة الصوت وطبقته لا يضمن أداءً عربيًا استوديويًا موحدًا على جميع الأجهزة؛ ذلك يتطلب تسجيلًا بشريًا مرخصًا أو مزود نطق عصبي عربي مناسبًا.

## البناء

- Android Gradle Plugin: 8.13.2
- Gradle: 8.13 (يضبطه GitHub Actions)
- Kotlin: 2.2.21
- JDK: 17
- Compile SDK: 36

لبناء APK محليًا من Android Studio، افتح مجلد المشروع `mahakama_project` وانتظر اكتمال مزامنة Gradle، ثم اختر `Build > Build APK(s)`.

في GitHub Actions، يشغّل الملف `.github/workflows/android.yml` الأمرين `assembleDebug` و`testDebugUnitTest`. يوجد ملف APK الناتج كـ artifact باسم `mahakama-debug-apk` عند نجاح المهمة.

## التخزين والصوت

الإجابات والاسم والكتابة الحرة وقرار كتم الموسيقى تُحفظ محليًا باستخدام Preferences DataStore. تم تعطيل Android backup في هذه المرحلة حتى لا تُنسخ هذه البيانات تلقائيًا عبر ميزة النسخ الاحتياطي للنظام. الموسيقى مضمّنة محليًا ولا تحتاج إلى الإنترنت.

## ملاحظات على التحقق من هذه التعديلات

تم تشغيل تحقق مستقل على منطق Kotlin الذي لا يعتمد على Android للتحقق من عدد الأسئلة، وفرادة العقد والنصوص، وسلامة روابط الانتقال، والوصول إلى جميع الأسئلة، وبعض حالات الوقت وسياسة الصوت. أُضيف كذلك اختبار تخزين على Android Emulator إلى سير GitHub Actions. لكن **لم يكتمل بناء Android محليًا في بيئة إعداد هذا الأرشيف**: فتنزيل Gradle 8.13 فشل بسبب تعذر حل `services.gradle.org`، ولا يوجد Android SDK محلي مضبوط؛ كما لم يُشغّل سير GitHub Actions من هذا السياق. لذلك فالكود وملفات الاختبار مُحدّثة، لكن لا أدّعي أن APK بُني أو اجتاز اختبارًا فعليًا على جهاز حتى تنجح مهام CI أو يُختبر من Android Studio.
